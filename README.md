# Shopee販売価格シミュレータ

東南アジアEC「Shopee」向けの販売価格・利益・利益率を双方向に計算するシミュレータです。社内利用向けに、ブラウザだけで完結する単一HTMLファイルとして構築しました。

🔗 **公開URL：** https://kopelliko.github.io/shopee-pricing-simulator/

---

## 主な機能

- **双方向計算** — 現地販売価格、日本円販売価格、利益額、利益率の4つの欄のどれを編集しても、残りの3つが自動で連動
- **7か国対応** — SG / TH / MY / TW / PH / VN / BR
- **為替レート自動取得** — currency-api（無料CDN）から1日1回更新、APIダウン時は固定値にフォールバック、手動編集も可能
- **重量別送料テーブル内蔵** — 0.05kg〜30kg、7か国分（合計440行 × 7か国）
- **手数料の自動適用** — 国別の販売手数料・決済手数料・FSS&CCB・その他を自動計算
- **DP割引・バウチャー対応** — 値引きを反映した実質利益を算出
- **画面内ヘルプ** — タイトル横の「?」ボタンで使い方を表示

---

## 使い方（3ステップ）

### 1. 左パネルで前提条件を入力

| 項目 | 内容 |
|---|---|
| 原価 | 商品の仕入価格（日本円） |
| 国内送料 | 日本国内での発送費用 |
| 出品先の国 | SG/TH/MY/TW/PH/VN/BR から選択 |
| 重量 | 商品の重量（kg、0.05刻みで切り上げ） |
| DP割引 | Daily Promotion等の店舗側割引率（%） |
| バウチャー割引 | クーポン等の割引率（%） |

### 2. 右パネルの4つの欄のどれか1つを編集

- 現地販売価格（SGD等）
- 日本円販売価格
- 利益額（円）
- 利益率（%）

編集中の欄はオレンジ枠でハイライトされます。

### 3. 残りの3つが自動計算される

例：「利益率」欄に `25` と入れる → 利益率25%を達成するための販売価格と利益額が即座に表示されます。

## 計算ロジック

元のShopee暫定シミュレータ（Excelスプレッドシート）のロジックを完全再現しています。

```
販売価格(JPY) = (原価 + 国内送料 + 重量別送料) ÷ (1 − (元手数料% + DP% + バウチャー%) / 100)

値引後価格 = 販売価格 × (1 − DP%) × (1 − バウチャー%)

利益 = 値引後価格 − 販売価格 × 元手数料%/100 − 原価 − 重量別送料 − 国内送料

利益率 = 利益 ÷ 値引後価格
```

### ポイント

- **販売価格の逆算**では「元手数料 + DP + バウチャー」を実効費用率として使用
- **手数料額の計算**では「元手数料のみ」を使用（DP・バウチャーは値引きとして値引後価格に既に反映されているため、二重計上を避ける）

## 注意事項（重要）

### 実態とのズレについて

シミュレータは元シートのShopee想定料率を使用していますが、過去の検証で以下が判明しています：

| 国 | シミュレータ手数料 | 実データ手数料 | 備考 |
|---|---|---|---|
| PH（フィリピン） | 27% | 約17% | シミュレータは保守的に算出 |
| TH（タイ） | 23% | 約30%（純Shopee手数料5% + VAT・関税） | 関税が大きく影響 |

### 運用ルール

1. **実際のPayment Detailと突き合わせて、自分の商品・国における実態係数を把握**してから判断してください
2. 関税は商品カテゴリ・時期で変動するため、シミュレータには含まれていません
3. タイなど関税が大きい国向けは、シミュレータの利益率に対し**さらに余裕**を見ることをおすすめします
